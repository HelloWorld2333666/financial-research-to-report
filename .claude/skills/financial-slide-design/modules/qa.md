# Design QA

**Principles:** QA1–QA4.

**Before accepting a slide:**
1. Render it at 1280×720 (`render_slides.py`).
2. QA must find no errors (overflow, overlap, out of bounds), and integrity must pass with no unsourced figures.
3. Compare it once with the one or two references retrieved for it.
4. Check the colour roles (QA3): is burgundy only on focal data, and gold only on structure?

**At deck level (planned):**
- repeated focal figures;
- identical compositions on consecutive slides.

**Known limits:**
- **Near-miss alignment warnings** are advisory.
- **The "small primary visual" warning** doesn't apply to multi-module pages.
